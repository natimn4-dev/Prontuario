# Verificação de acesso do GitHub

Teste técnico realizado em 20 de agosto de 2026 para confirmar que o conector consegue criar uma branch isolada, gravar e editar um arquivo, gerar commits, publicar a branch e abrir um pull request em rascunho.

## Etapas validadas

- branch isolada criada a partir de `main`;
- arquivo criado e posteriormente editado;
- commits registrados na branch;
- branch publicada no repositório remoto.

Este arquivo não altera código, configuração, dados clínicos ou comportamento do aplicativo e pode ser removido ao encerrar a verificação.
