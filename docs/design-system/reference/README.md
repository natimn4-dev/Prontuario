# Design Target References

Este diretório registra conceitualmente as prévias aprovadas que orientam o PA-CDS v1.0.

Referências aprovadas nesta rodada:

1. tela de Escalas Clínicas — cards por domínio, checkboxes, estado aplicada e resumo das selecionadas;
2. Relatório Longitudinal — layout A4 vertical, cards limpos, hierarquia roxo/ameixa e evolução longitudinal;
3. Tabela de Medicações — horários estruturados, checkboxes, preview de impressão;
4. workspace clínico completo — sidebar persistente com marca e paciente;
5. gráfico longitudinal — seis dimensões separadas, eixo temporal, consulta atual destacada e estados sem redução/atenção/redução identificada.

As imagens originais usadas durante a revisão não são armazenadas aqui quando houver qualquer dúvida sobre origem/dados. Apenas referências sintéticas e aprovadas podem ser adicionadas ao repositório.

Qualquer alteração material do design target exige nova prévia visual e aprovação explícita antes de produção.
