# Verificação de acesso do GitHub

Teste técnico realizado em 20 de agosto de 2026 para confirmar que o conector consegue criar uma branch isolada, gravar um arquivo, gerar commit, publicar a branch e abrir um pull request em rascunho.

Este arquivo não altera código, configuração, dados clínicos ou comportamento do aplicativo e pode ser removido ao encerrar a verificação.
