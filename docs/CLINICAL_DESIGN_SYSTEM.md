# Prontuário Aprimorado Clinical Design System

A referência oficial e versionada do sistema visual passou a ser:

`docs/design-system/README.md`

Use o **PA-CDS v1.0 — Minimal Clinical Premium · Geriatric HealthTech** como contrato de interface para novas funcionalidades e revisões.

Alterações metodológicas, clínicas, de infraestrutura ou de persistência não devem substituir silenciosamente o design aprovado.

O fluxo obrigatório para mudanças materiais de UI é:

**branch → CI → prévia visual/funcional → aprovação → merge → deploy → smoke**.

O gráfico longitudinal aprovado de capacidade intrínseca e independência funcional faz parte explícita desse contrato visual.
